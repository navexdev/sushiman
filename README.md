\# 🍣 Sushiman



A responsive Japanese food website built with \*\*HTML\*\* and \*\*CSS\*\* as a frontend practice project.



The project focuses on building a modern responsive layout, working with CSS positioning and Flexbox, and creating a visually appealing multi-section website.



\## ✨ Features



\* 🍣 Japanese food themed design

\* 📱 Responsive layout

\* 🧭 Navigation menu

\* 🎨 Custom CSS styling

\* 🖼️ Hero section with images and overlays

\* 📋 Multiple content sections

\* ✨ Scroll animations

\* 📐 Flexbox-based layouts

\* 🎯 Responsive positioning and sizing



\## 🛠️ Technologies



\* \*\*HTML5\*\*

\* \*\*CSS3\*\*

\* \*\*JavaScript\*\*

\* \*\*AOS (Animate On Scroll)\*\*



\## 🚀 Getting Started



\### 1. Clone the repository



After the project is published on GitHub, clone the repository:



```bash

git clone https://github.com/Navid7901/sushiman

```



\### 2. Open the project



Navigate into the project directory and open `index.html` in your browser.



You can also use a local development server such as \*\*VS Code Live Server\*\*.
